# ComfyUI-ScenarioExtractor (시나리오 추출기)

ComfyUI 환경에서 한 줄 아이디어로부터 **독립 세션 검수(확증 편향 0%)** 및 **Context Loop 오버랩 규칙(39프레임/1.6초 연속성 버퍼)**이 적용된 42초 롱테이크 비디오 프롬프트를 자동 생성하는 커스텀 노드 패키지입니다.

---

## 🌟 주요 특징

1. **독립 검수자 (Zero Confirmation Bias)**:
   - 작가 세션의 맥락 기억을 완전히 배제한 무상태(Stateless) API 세션을 호출하여 대본 초안을 객관적으로 검수합니다.
   - 번역투("너클이 하얗게 질린다" ➔ "손마디가 하얗게 굳는다") 및 비디오 렌더링에 부적합한 추상적 내면 묘사를 구체적 신체 동작으로 교정합니다.

2. **Context Loop 엔진 오버랩 보정 (42초 롱테이크 완성)**:
   - 15초 단위 3개 씬 연결 시 발생하는 **39프레임($22\text{ trim} + 17\text{ blend} \approx 1.63\text{초}$) 소실** 문제를 해결합니다.
   - Shot 2, Shot 3 프롬프트의 앞부분 1.6초 구간에 직전 씬의 물리적 모션을 자연스럽게 이어받는 버퍼 지시문을 자동 주입합니다.

3. **제로 디펜던시 (Zero Dependency)**:
   - 별도의 무거운 SDK 설치 없이 파이썬 기본 표준 라이브러리(`urllib.request`)만을 사용하여 충돌 없이 빠르고 안정적으로 동작합니다.

---

## 🧩 노드 구성

- **✍️ 시나리오 작가 (`ScenarioWriter`)**: 상황 아이디어와 인물 묘사로부터 45초 3개 씬 초안 작성
- **🧐 독립 검수자 (`ScenarioAuditor`)**: 기억이 없는 깨끗한 세션에서 번역투 및 물리적 연속성 결함 교정
- **⚙️ Context Loop 프롬프트 컴파일러 (`ContextLoopCompiler`)**: 39프레임 오버랩 소실 보정 규칙이 적용된 영문 비디오 프롬프트 3개 배출
- **🎬 시나리오 추출기 올인원 (`ScenarioExtractorAllInOne`)**: 위 3단계를 단일 노드에서 원클릭으로 일괄 처리

---

## 🔑 API 키 설정
- 노드의 `api_key` 위젯에 직접 입력하거나,
- 터미널 환경변수 `export GEMINI_API_KEY="your-api-key"`를 설정해 두면 자동으로 인식합니다.
